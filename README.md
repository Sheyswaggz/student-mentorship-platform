# Student Mentorship Platform

A full-stack student mentorship platform built with modern web technologies, enabling seamless connections between students and mentors with real-time communication, scheduling, and progress tracking capabilities.

## 🚀 Tech Stack

### Frontend
- **Next.js 14+** - React framework with App Router for server-side rendering and routing
- **React 18** - UI component library
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first CSS framework

### Backend
- **Next.js API Routes** - Serverless API endpoints
- **Express.js** - Additional API server capabilities
- **Prisma** - Type-safe ORM for database operations
- **PostgreSQL** - Primary relational database
- **Redis** - Caching and session management

### Development Tools
- **ESLint** - Code linting with Next.js and TypeScript rules
- **Prettier** - Code formatting
- **Jest** - Testing framework
- **TypeScript** - Static type checking

## 📋 Prerequisites

Before you begin, ensure you have the following installed:

- **Node.js** >= 20.0.0
- **npm** >= 10.0.0
- **PostgreSQL** >= 14.0
- **Redis** >= 6.0 (optional for development, required for production)
